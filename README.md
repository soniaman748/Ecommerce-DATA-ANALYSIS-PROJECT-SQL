# Ecommerce-DATA-ANALYSIS-PROJECT-SQL

This project focuses on analyzing an **E-Commerce dataset using MySQL** to understand customer behavior, product performance, sales trends, and business growth opportunities.

The analysis uses four relational tables — **Customers, Products, Orders, and OrderDetails** — to answer real-world business questions using SQL.

## 🎯 Project Objective

The main objective of this project is to transform raw e-commerce transaction data into meaningful business insights that can help a company:

- Identify key customer markets
- Understand customer purchasing behavior
- Identify high-demand products and categories
- Analyze monthly sales performance
- Track Average Order Value (AOV)
- Identify products requiring frequent restocking
- Find products with low customer reach
- Analyze new customer acquisition trends
- Support marketing, inventory, and staffing decisions

## 🗂️ Dataset Structure

| Table | Purpose |
|---|---|
| `customerecom` | Customer information such as customer ID and city |
| `productsecom` | Product information such as product ID, name, and category |
| `ordersecom` | Order-level information such as order date, customer, and total amount |
| `orderdetailsecom` | Product-level order details such as quantity and price per unit |

## 📊 Key Business Analysis

Some of the questions answered in this project include:

- Which cities have the highest number of customers?
- What is the customer order-frequency distribution?
- Which products generate the highest revenue within a specific purchase pattern?
- Which product category has the highest customer demand?
- What is the month-on-month sales trend?
- Which month experienced the largest sales decline?
- How does Average Order Value change over time?
- Which products have the highest sales frequency?
- Which products are purchased by less than 40% of customers?
- How is new-customer acquisition changing over time?
- Which months have the highest sales and may require additional inventory and staff?
